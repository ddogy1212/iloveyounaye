# 음성위젯 4.0 — Android 1×1 음성 재생 위젯

- 새 영상 `ㄹㅇ 나예.mp4`에서 추출한 음성으로 재생합니다.
- 위젯을 탭하면 앱 화면 전환 없이 기존처럼 서비스에서 음성이 재생됩니다.
- 앱 안의 **사진 선택하기**에서 사진을 열고, 미리보기에서 손가락으로 이동하거나 두 손가락으로 확대/축소한 다음 **이 사진과 범위로 위젯 적용**을 탭하면 홈 화면 위젯이 즉시 바뀝니다.
- 선택한 사진과 크롭 설정 결과는 앱의 내부 저장소에 보관됩니다.
- 1×1 위젯 오른쪽 아래의 하트 배지를 없앴습니다.
- 앱 표시 이름은 **음성위젯**으로 유지하되, 패키지 ID를 `com.iloveyounaye.voicewidgetcustom`으로 바꿔 기존 APK와 설치 충돌이 발생하지 않도록 했습니다.
- Android 8.0 이상을 대상으로 개발했습니다.

## 설치

Release의 APK를 다운로드해 설치하고 앱을 실행한 뒤 위젯 추가 버튼을 누르세요. 기존 음성위젯은 지우지 않아도 되지만 기존 위젯은 자동으로 변경되지 않으므로 새 앱의 위젯을 다시 추가하세요.

## 개인정보

사진은 기기 내부에만 저장되고, 사용자가 고른 사진은 서버로 전송되지 않습니다. **초기 사진과 음성은 이 공개 GitHub 저장소에 포함**됩니다.
