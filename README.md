# 음성위젯 v8 — 1×1 사진 + 두 음성 번갈아 재생

- Android 8.0+ / `com.iloveyounaye.voicewidgetliveframe`
- **위젯 첫 터치:** 원래 음성
- **위젯 두 번째 터치:** 사용자가 가져온 새 음성
- **위젯 세 번째 터치:** 다시 원래 음성 (이후 반복)
- 터치할 때마다 이전 재생을 멈추고 선택된 음성의 처음부터 재생합니다.
- 음성 미리 듣기 버튼은 위젯 터치 순서를 바꾸지 않습니다.
- 기존 1×1 사진 위젯, 사진 확대/이동/자동 반영 기능을 유지합니다.
- **사적인 두 번째 음성은 공개 GitHub 저장소와 빌드된 APK에 포함하지 않습니다.** 앱에서 고른 파일이 사용자의 기기 내부 저장소에만 복사됩니다.

## 사용법

1. [Releases](https://github.com/ddogy1212/iloveyounaye/releases)에서 최신 v8 APK를 설치합니다.
2. 합쳐진 `.m4a` 파일을 휴대전화에 다운로드합니다.
3. 음성위젯 앱에서 **🎵 두 번째 음성 선택하기** → 다운로드한 파일을 선택합니다.
4. 홈 화면의 기존 1×1 위젯을 누릅니다. 원래 음성→새 음성→원래 음성 순서로 반복됩니다.
5. 음성을 새로 선택하면 다음 터치는 원래 음성부터 다시 시작합니다.

## 기존 앱 위에 업데이트 설치

패키지 ID는 v7과 같고, `versionCode`는 1에서 2로 올렸습니다. 따라서 **기존 v7과 새 APK의 서명이 동일할 때** 기존 앱의 설정과 위젯을 유지한 채 업데이트 가능합니다.

**중요:** 이 프로젝트의 GitHub Actions는 기본 Android 디버그 APK를 생성합니다. GitHub 호스팅 실행기에서 생성되는 debug key가 이전 설치본과 다르면 Android에서 업데이트를 거절합니다. 이때는 새로운 APK를 덮어씌울 수 없으며, 기존 APK의 서명 키가 없으면 설치된 앱을 업데이트할 방법이 없습니다. 기존 앱을 삭제하면 앱 내부에 저장한 사진과 설정이 사라질 수 있으니 주의하세요.

앞으로 안정적으로 업데이트하려면 개인 릴리스 키를 안전하게 보관하고 GitHub Secrets를 통해 서명하는 별도 배포 방식이 필요합니다. **서명 키를 공개 저장소에 절대 커밋하지 마세요.**
