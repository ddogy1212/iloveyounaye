# 음성위젯 NEW v9 — 별도 설치용 앱

기존 음성위젯 설치 시 '패키지 서명 충돌'이 발생하여 새 앱으로 재빌드한 버전입니다.

- 앱 이름: **음성위젯 NEW**
- 앱 ID: `com.iloveyounaye.voicewidgetstandalone2026` (이전 `com.iloveyounaye.voicewidgetliveframe`과 다름)
- 홈 화면 1×1 사진 음성 위젯. 위젯을 탭하면 **원래 음성 → 추가 음성 → 원래 음성 → 추가 음성** 순서로 재생
- 새 음성은 앱의 **🎵 두 번째 음성 선택하기**에서 직접 가져오기; 기기 내부에만 저장하고 GitHub나 서버로 업로드하지 않음
- 이전 앱을 삭제할 필요 없음. 단, **이전 앱 위젯은 새 앱과 별개로 작동하므로** 새 위젯을 추가해야 함
- 기존 앱의 사진 설정은 새 앱으로 자동 복사되지 않음. 새 앱에서 사진을 새로 선택 가능
- 이 앱을 설치한 이후의 추가 업데이트는 Android APK 서명키가 동일해야만 가능

[APK 다운로드](https://github.com/ddogy1212/iloveyounaye/releases/tag/v9.0.0-new-separate-app)

## 설치 순서

1. 음성위젯 NEW v9 APK 설치
2. 기존 대화에서 합쳐놓은 M4A 파일을 휴대전화에 저장
3. 새 앱 실행 → **두 번째 음성 선택하기** → 그 M4A 파일 선택
4. 새 앱에서 **홈 화면에 1×1 위젯 추가** → 홈 화면에서 탭해 확인

**개인 음성 파일은 공개 GitHub에 추가하지 않습니다.**
